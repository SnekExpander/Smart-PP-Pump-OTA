# Smart-PP-Pump-OTA

Download [sppp-esp32-c3-update.bin](sppp-esp32-c3-update.bin) and upload it through **System → Firmware update**. This is the signed update package used by the pump's online updater.

For USB flashing, use the versioned factory image from [Smart PP-Pump Releases](https://github.com/SnekExpander/Smart-PP-Pump/releases).
